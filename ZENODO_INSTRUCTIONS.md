No DOI has been generated or reserved by this package. No GitHub Release is
created automatically. The pushed Git tag v1.0.0 identifies the audited snapshot.

1. Sign into Zenodo with your own account and connect your GitHub account.
2. In Zenodo's GitHub settings, enable williamjay1/fx-reference-tail-forecasting.
3. On GitHub, create a Release from the existing v1.0.0 tag. Do this after
   enabling the integration. Check the author, ORCID and title before deposit.
4. Check the resulting Zenodo record and its archived files. Copy the version
   DOI and concept DOI separately. Use the version DOI to identify this exact
   replication package in the manuscript; retain the concept DOI for the
   project as a whole. A Zenodo record is a software/data deposit, not the
   paper's journal publication DOI.

CITATION.cff and .zenodo.json are consistent. Zenodo gives .zenodo.json
precedence when both are present. The package's primary deposit is software
(MIT); the description explicitly preserves separate data and third-party
reuse conditions. Recheck the resulting metadata and mixed licensing.
